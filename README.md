# Radiance Cascades Compared to Unity’s Standard Global Illumination Methods

DIGRA conference experiment setup.

This repository contains the experimental materials for the paper "Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP".

## Contents

- Raw FPS and frame time datasets in `Measured Data/`
- Generated figures used in the paper
- [Render videos for visual comparison](https://www.youtube.com/watch?v=daDjPJyB86o&list=PLaHv1eGKS6CyZF2IG05RV7KAHvvU5-xIQ)

## Measured data

The `Measured Data/` folder groups results by scene: `Isometric/`, `Realistic FPS/`, and `Stylized Fps/`. Each scene includes CSV files for the tested lighting methods and a `Performance_comparison_*.xlsx` workbook.
